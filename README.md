# 퇴근 파이터 / OFFICE RING

**[▶ 지금 플레이하기](https://brokenmental.github.io/office-ring-game/)**

직장 속 가상의 빌런을 상대로 펀치를 날리는 키보드 기반 1인칭 권투 게임입니다. 상대의 공격을 읽고 주먹으로 받아치거나, 몸을 피한 뒤 카운터를 노려보세요.

## 게임 소개

- **회사 접수 · 100라운드 승급전**: 깐족왕 동기부터 최대 주주까지, 회사를 접수하고 정시 퇴근에 도전합니다.
- **개별전과 세 가지 난이도**: 상대를 골라 한 판을 즐기거나 자신에게 맞는 난이도로 연습할 수 있습니다.
- **상대의 과거와 대화**: 오프닝 만화와 인물별 이야기를 보고 전투에 들어갑니다.
- **무료 플레이**: 후원 여부나 광고 시청을 플레이 조건으로 삼지 않습니다.

PC의 최신 브라우저와 키보드로 플레이하세요. 3D 인물 표현에는 WebGL을 사용합니다.

## 조작

| 키 | 동작 |
|---|---|
| J / K / L 또는 A / S / D | 화면 왼쪽 / 가운데 / 오른쪽 공격 |
| ↓ 누르고 있기 | 숙이기 |
| ← / → | 제자리 좌우 위빙 |
| 숙여서 J / L | 좌우 복부 공격 |
| 숙여서 K | 어퍼컷 |
| Space 또는 화면 클릭 | 대화·만화 진행 |
| Enter | 경기 시작·재도전·다음 상대 |
| Esc | 전투 일시정지 / 대화·만화 생략 |
| F | 집중 모드 |

상대 주먹이 오는 위치와 높이에 맞춰 펀치를 내면 충돌로 받아칠 수 있습니다. 타이밍에 맞춰 피한 뒤 적중하면 카운터입니다. 훅은 옆 위빙으로 피할 수 없고, 복부 공격은 숙여도 맞으니 상대 동작을 살펴보세요.

설정과 최고 기록은 현재 브라우저에 저장됩니다. 진행 중 새로고침하면 승급전은 처음부터 시작합니다.
