# 퇴근 파이터 / OFFICE RING

**[▶ 지금 플레이하기](https://brokenmental.github.io/office-ring-game/)**

직장 속 가상의 빌런을 상대로 펀치를 날리는 키보드 기반 1인칭 권투 게임입니다. 상대의 공격을 읽고 주먹으로 받아치거나, 몸을 피한 뒤 카운터를 노려보세요.

## 게임 소개

- **회사 접수 승급전**: 현재는 개별 만화가 완성된 첫 12명까지 플레이할 수 있습니다. 12번째 업무 떠넘김 선임을 이기면 다음 라운드 준비중 안내와 다시하기 버튼이 나옵니다. 전체 이야기는 100라운드로 기획되어 있습니다.
- **순서대로 강해지는 상대**: 플레이 방식은 하나이며 라운드에 따라 상대의 속도·체력·공격 조합이 강해집니다. 저장된 라운드를 자동으로 불러옵니다.
- **자동 도입 만화와 인물 이야기**: 이 브라우저에서 처음 플레이할 때 주인공이 왜 싸우기로 했는지 만화로 시작합니다. 이후 새로고침/재접속은 만화를 생략하며 진행 초기화를 하면 다시 표시합니다. 진행하거나 건너뛰면 선임 연습 또는 저장한 상대의 소개로 이어집니다. 초반 열 동기와 선임 두 명의 개별 과거 만화가 있으며, 주인공의 지하실 대결 신청과 회사 전체의 대결 모드 전환이 이어집니다.
- **무료 플레이**: 후원 여부나 광고 시청을 플레이 조건으로 삼지 않습니다.

최신 브라우저에서 키보드 또는 모바일 터치 버튼으로 플레이하세요. 인물·팔·글러브는 튜토리얼과 같은 카툰 파츠로 표시합니다. [카툰 자산 출처](assets/fighters/CREDITS.md)를 확인할 수 있습니다. WebGL 표현은 파츠 로딩 실패 시 대체 경로입니다.

튜토리얼은 강조 영역과 큰 키 표시로 다음 입력을 안내합니다. 수비 연습에서는 선임의 주먹이 천천히 다가오다가 누를 순간에 멈추고, A/J 또는 ↓와 주먹 위 타이밍 원이 밝아집니다. 올바르게 펀치로 받아치거나 숙이면 진행합니다. 모바일에서는 해당 방향과 타격 버튼을 함께 강조하며, 숙이기 단계는 중하 방향만 누릅니다. 일반 경기 속도는 그대로입니다.

복부 공격을 받아치는 연습도 좌우 각각 진행합니다. **↓를 누른 채 화면 왼쪽 공격은 J/A, 오른쪽 공격은 L/D**로 타이밍에 맞춰 맞부딪치세요. 숙이기만 하거나 서서 치면 복부 공격을 막을 수 없고, 가운데 K/S 어퍼컷도 충돌 방어가 아닙니다. 모바일은 **좌하 또는 우하를 누른 채 타격**합니다. 공격 버튼은 항상 펀치이며 누른 채 기다리는 가드로 바뀌지 않습니다.

## 조작

| 키 | 동작 |
|---|---|
| J / K / L 또는 A / S / D | 화면 왼쪽 / 가운데 / 오른쪽 공격 |
| ↓ 누르고 있기 | 숙이기 |
| ← / → | 제자리 좌우 위빙 |
| 숙여서 J / L | 좌우 복부 공격 |
| 숙여서 K | 어퍼컷 |
| 화면 어디든 클릭·터치 또는 Space | 대화·만화 진행 |
| Space (Enter도 가능) | 경기 시작·재도전·다음 상대 |
| Esc | 전투 일시정지 / 대화·만화 생략 |
| F | 집중 모드 |

상대 주먹이 오는 위치와 높이에 맞춰 펀치를 내면 충돌로 받아칠 수 있습니다. 타이밍에 맞춰 피한 뒤 적중하면 카운터입니다. 카운터에 맞은 상대는 1초간 공격·반격을 멈추고 가드만 가능한 그로기에 빠지며 머리 주변 효과와 표시로 확인할 수 있습니다. 추가 타격으로 그로기 시간은 늘어나지 않습니다. 공격이 들어오는 화면 위치를 기준으로 왼쪽 공격은 →, 오른쪽 공격은 ←, 가운데 공격은 ← 또는 →로 피합니다. 상단·복부와 직선·훅·어퍼컷에 모두 적용됩니다. 복부 공격은 숙이기만 하면 맞습니다.

튜토리얼은 복부 충돌 뒤 위빙 6단계를 진행합니다. 모바일에서는 위빙 방향만 강조하며 가운데 공격은 좌우를 모두 강조합니다. 위빙 단계는 숙이기만으로 넘어갈 수 없습니다.

진행·클리어 기록·최고 점수와 소리/화면 설정을 현재 브라우저에 저장합니다. 새로고침 후 해당 라운드 처음부터 이어갑니다. 기존 여러 난이도 저장은 가장 멀리 진행한 기록을 보존해 통합합니다. 저장이 차단되면 현재 창에서만 유지합니다.

설정에는 소리 ON/OFF·조작법·화면 효과 줄이기·진행 초기화가 있습니다. 화면 효과 줄이기는 흔들림/확대/반동과 그로기 일렁임을 줄이며 공격 판정은 바꾸지 않습니다. 초기화는 확인 후 진행/클리어만 지우고 설정/최고 점수는 유지합니다. 전체화면 버튼도 제공합니다(미지원 시 화면 확대). 모바일은 왼쪽 6방향 패드와 오른쪽 타격 버튼을 사용합니다. 좌하/우하를 누른 채 타격하면 복부 공격, 중하를 누른 채 타격하면 어퍼컷입니다.

만화에는 다음 버튼 없이 “Space 키를 누르거나 화면을 누르면 넘어갑니다.” 안내가 표시됩니다. 글자가 출력 중이면 첫 입력은 문장을 완성하고 다음 입력으로 진행합니다. 대사에는 개별 인물 만화 또는 공용 상황 삽화가 표시됩니다. 튜토리얼은 A/S/D 중심의 현재 단계 안내 하나로 진행합니다.


## 이용·권리 안내

플레이와 공식 링크 공유를 환영합니다. 공개 저장소가 코드·그림 등의 자유로운 재배포나 재호스팅을 허용한다는 뜻은 아닙니다. 법정 예외, GitHub 약관상의 권리, CC0 자산 및 AI 생성물의 권리 범위는 구분합니다.

[이용·권리 안내](https://brokenmental.github.io/office-ring-game/legal.html) · [이용 조건 원문](TERMS.md) · [3D 자산 출처](https://brokenmental.github.io/office-ring-game/assets/human/CREDITS.html)

화면을 회전하면 눌려 있던 터치 입력을 해제합니다. 회전 후 버튼을 다시 누르세요.

만화·상대 소개가 열려 있는 동안 뒤쪽 버튼은 눌리지 않습니다. 화면 어디든 눌러 진행하거나 건너뛰기를 사용하세요.

이 게임의 모든 캐릭터는 AI를 활용해 만든 허구의 인물이며, 실제 인물·단체와 관련이 없습니다.

만화의 허구 인물 안내는 이미지 우측 상단에 두 줄로 표시합니다. 저장된 라운드의 이어하기 화면과 경기 결과 화면은 불투명하게 표시해 뒤의 상대를 가립니다.

튜토리얼과 일반 전투 모두 카툰 인물과 주먹을 사용합니다. 상대 장갑은 옆면 가드에서 공격에 맞는 면으로 바뀌고, 어깨·팔꿈치·손목은 연결된 윤곽으로 움직입니다. 100명 외형 설정은 성격별 얼굴군 11종과 의상 4종에 체격·나이·색·소품을 조합합니다. 플레이 구간은 개별 만화가 완성된 첫 11라운드까지입니다.
